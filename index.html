ตั้งค่า Google Sheets + Apps Script

คุณสามารถนำ Google Apps Script Web App URL มาใส่ช่องด้านล่าง เพื่อบันทึกคะแนนจริงลง Google Sheets และดึง Leaderboard แบบเรียลไทม์ได้ทันทีครับ

หากเว้นว่างไว้ ระบบจะใช้ Mock Local Storage เพื่อให้เล่นเกมได้สมบูรณ์

📋 วิธีติดตั้ง Google Sheets เชื่อมต่อเกมใน 4 ขั้นตอน:
  1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู ส่วนขยาย (Extensions) → Apps Script
  2. ลบโค้ดเดิมทั้งหมด วางโค้ดด้านล่างนี้ลงไป แล้วกดเลือกฟังก์ชัน setupSheet กด Run (เรียกใช้) 1 ครั้งเพื่อสร้างหัวตารางอัตโนมัติ
  3. กดปุ่มสีน้ำเงิน การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)
  4. เลือกประเภท เว็บแอป (Web app), ตั้งค่าใครมีสิทธิ์เข้าถึงเป็น "ทุกคน" (Anyone), กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย /exec มาวางในช่องด้านบน
📚 คลังคำถามขยายใหม่ 3,000+ ข้อ (Question Bank Manager) Expanded 3,000+ Question Bank

ระบบรองรับชุดคำถามกว่า 3,000+ ข้อจากไฟล์แบตช์ต่างๆ อัตโนมัติ
